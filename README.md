### Hi, I'm Ashlee 👋

At Vellum, I started on the developer platform for prompts, workflows, evaluations, and SDKs, and now lead a team building [Vellum Assistant](https://github.com/vellum-ai/vellum-assistant), an open-source personal AI assistant for web, desktop, mobile, and messaging.

The questions I keep coming back to are where an assistant should follow a rule and where it should use judgment, and whether it can learn from its own mistakes without someone pointing them out.

A lot of that comes down to what the assistant has in front of it when it decides, so that's where the experiments are right now: how much context an agent actually needs per turn, whether it anchors on its own earlier drafts instead of going back to the sources (using an eval set built from real corrections), and distilling the memory selection step from a frontier model into a small local model fine-tuned on its own logs.
